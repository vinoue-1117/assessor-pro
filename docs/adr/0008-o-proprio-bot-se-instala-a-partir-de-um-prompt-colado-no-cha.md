# O próprio bot se instala, a partir de um prompt colado no chat

O dono cola no chat do bot o prompt de instalação, que diz a função do bot e a pasta dele. O bot lê a ficha e o procedimento de instalação na stable, confere pela função se é ele mesmo, grava o perfil e os ponteiros e devolve uma checklist. O mesmo prompt serve para atualizar. A identidade vale pela função porque o nome do bot no chat varia de conta para conta.

## Alternativas consideradas

Um bot de configuração que instalaria os outros: na plataforma cada bot só altera a si mesmo. Instalação por marketplace: deixou de existir.
