# O bot instalado guarda só ponteiros e busca a skill completa na stable a cada uso

O que fica gravado no bot é o perfil e um ponteiro por skill, com description fixa. A skill completa vem da stable a cada uso, então uma correção promovida chega a todos os bots sem reinstalar, e mudar o texto da skill completa não altera o que está instalado.

## Alternativas consideradas

Copiar a skill inteira, ou a description dela, para o bot. Obrigava a reinstalar à mão em cada bot toda vez que o texto mudava.
