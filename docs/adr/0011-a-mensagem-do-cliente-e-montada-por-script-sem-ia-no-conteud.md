# A mensagem do cliente é montada por script, sem IA no conteúdo

O script lê os relatórios, cruza com a planilha de clientes e monta a mensagem de cada conta. O bot não edita, não resume e não arredonda nada. Para mudar a mensagem, corrige-se a planilha, o discurso macro ou o modelo e prepara-se o lote de novo, de modo que o conteúdo aprovado é exatamente o que sai.
