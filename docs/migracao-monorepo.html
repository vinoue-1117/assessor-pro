A migração, passo a passo

A faixa embaixo de cada passo mostra o que os bots dos assessores estão fazendo naquele momento.

1

Abrir a PR

O GitHub roda o check sozinho.

bots normais
2

Merge na main

Nenhum bot percebe: eles leem a stable.

bots normais
3

Promover

A stable ganha os endereços novos e perde os antigos.

git push origin main:stable
bots param
4

Reinstalar

O bot de configuração troca os ponteiros. Planilha e histórico ficam.

param até aqui
5

Testar

Um envio de teste para você mesmo.

assessor-envio-teste
bots normais

Parado quer dizer: o bot responde "não consegui baixar as instruções" e não envia nada.

Por que param no passo 3

O ponteiro antigo procura a skill em plugins/…. Depois da promoção esse endereço não existe mais.

Como voltar atrás

Antes de reinstalar, a stable volta ao ponto anterior e os ponteiros antigos funcionam de novo.

git push --force origin 9ae4fc8:stable
