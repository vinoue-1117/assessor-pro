# Triage labels

As skills falam em cinco papéis canônicos de triagem. Este arquivo liga cada papel ao nome do label usado no issue tracker deste repo.

| Label em mattpocock/skills | Label no nosso tracker | Significado                                      |
| -------------------------- | ---------------------- | ------------------------------------------------ |
| `needs-triage`             | `needs-triage`         | O mantenedor precisa avaliar a issue             |
| `needs-info`               | `needs-info`           | Aguardando mais informação de quem abriu         |
| `ready-for-agent`          | `ready-for-agent`      | Especificada por inteiro, pronta para um agente  |
| `ready-for-human`          | `ready-for-human`      | Exige implementação humana                       |
| `wontfix`                  | `wontfix`              | Não será feita                                   |

Quando uma skill citar um papel (por exemplo, "apply the AFK-ready triage label"), usar o nome de label correspondente nesta tabela.

Para trocar o vocabulário, editar a coluna "Label no nosso tracker".
